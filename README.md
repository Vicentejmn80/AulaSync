# Aulasync

AI-Powered Academic Management System. An intelligent assistant designed for educators that automates assignment creation, calendar planning, and curricular adaptations with OpenAI API. Built with Laravel 11, Livewire, Alpine.js, and Tailwind CSS. Includes a natural language command system for real-time classroom management.

## Repository structure

- `backend/` — Laravel API and web application
- `frontend-android/` — Android client

## Deployment

The backend includes a production `Dockerfile` for Render (PHP 8.2, Nginx, PostgreSQL via Supabase).
